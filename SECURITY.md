# Security

This is a disposable sandbox for testing [dev-pipeline](https://github.com/brianm-di4u/dev-pipeline)'s merge gate. Nothing here is deployed or released for use.

## Reporting a vulnerability

Report it privately: on this repository's **Security** tab, choose **Report a vulnerability**. Please don't open a public issue or PR about it.

A weakness in the pipeline itself, such as a way past the gate, belongs to dev-pipeline: report it on [its Security tab](https://github.com/brianm-di4u/dev-pipeline/security) instead, because every project using the pipeline shares it.

## Supported versions

Only the latest commit on `main`.
